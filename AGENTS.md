# Verbos project guidance

## CFA workflow

CFA workflow: new-product development

Verbos is still being shaped as a new product. Continue using CFA App Creation
for requested product design and the relevant CFA skills for bounded feature,
test and tidy-up work. The presence of an Xcode project or commits does not
switch this project into established-product maintenance.

Preserve the current approved UI and brand: Verbos: Learn Spanish. New-product
development is not blanket permission to redesign screens. Apply the current
request, reuse existing assets and components, and do not restore starter
defaults that Matthew Thomas has changed. Do not repeatedly offer themes,
Settings footers or branding changes.

Keep existing bundle identifiers and persisted-data compatibility unless an
explicit request authorizes a change.
