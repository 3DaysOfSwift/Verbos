# Verbos: Learn Spanish

A separate CFA iOS app adapted from Todays Twenty. Open Verbos.xcodeproj and run the Verbos scheme. Bundle ID: com.3DaysOfSwiftConcurrency.Verbos. The original maths app is unchanged.

The public brand is **Verbos: Learn Spanish**, with **Verbos** used in compact in-app headings. The project, scheme, app module and source folder are Verbos; the test target is VerbosTests. The opaque 1024-pixel app icon is installed in Assets.xcassets/AppIcon.appiconset. See Branding/ICON.md for the generated artwork and prompt.

The complete internal rename changes the bundle identifier and storage directory. iOS treats this as a separate installation; progress and preferences from the earlier development app are not automatically transferred. That installation and its data are not removed. Git history is preserved.

## Daily practice

Choose a verb book and learning mode, then translate one Spanish conjugation into English using nine answer options. A person and tense accompany the word to disambiguate forms. Correct answers turn green; mistakes turn red. Reveal by tapping the word. Only correct first attempts score. Resolved questions advance after two seconds without dimming the interface.

Twenty scored answers complete the daily session. One optional extra session is allowed. Midnight unlocks the next day. Questions, focus and progress are saved after each action. The tab bar hides during play.

“Different verb” excludes the current verb. Shuffle and mode changes are allowed before starting and on question one; replacing question one resets its score. The verb and mode lock from question two onward. The shuffled, persisted deck cycles through all six people for the selected tense(s) before repeating.

Modes: present, finished past (preterite), used to/background (imperfect), future and mixed past/future. Default: mixed. Starts with ser as an editorial starting choice, not a measured popularity ranking. Current supported book/table intersection: ser, estar, querer. Do not automatically enable additional verbs without reviewing context-sensitive translations.

## Cuentiva data provenance

- Books: unchanged snapshot of GlobalEnglish-SpanishLearningBooksCollection/content/books.json (local repository HEAD 465feb4).
- Conjugations: unchanged Cuentiva/content/verbs/catalogue.json (local repository HEAD a103084). These are Cuentiva’s maintained forms, not invented or generated by an online model.
- The book reader can refresh from the exact same public GitHub release catalogue used by Cuentiva: https://github.com/3DaysOfSwift/GlobalEnglish-SpanishLearningBooksCollection/releases/latest/download/catalogue.json
- Release descriptors, payload lengths and SHA-256 checksums are verified before an atomic book-cache replacement. Failed updates keep the existing content. Current sessions retain their complete deck.
- The three current verb books teach the present tense. Past/future drills derive from the separate Cuentiva conjugation tables, not from claims that those stories teach those tenses.
- Verb tables are bundled and update with the app; book updates are explicitly requested in the book reader.
- Content retains its existing author/licensing/editorial-review notices. No new public content licence is granted. This project has not been published.

## Architecture

PracticeFeature owns daily sessions, scores and mode/verb locking. LibraryFeature owns supported Cuentiva books and tables, building questions through ConjugationQuestions. DayStreakFeature interprets practice history. SettingsFeature owns the preferred learning mode.

SwiftDataManager lazily opens Application Support/Verbos/Sessions.store. CuentivaContentRepository reads bundled content and maintains one replaceable Books.json cache; NetworkingManager wraps URLSession. AppModel.live composes these dependencies and exposes only Features. Each screen has its own ViewModel.

The book catalogue is not user progress. Network requests only download public books; answers and progress remain on the device. Settings and tab navigation never depend on a database or network startup gate.

## Language scope

Questions show an explicit subject and infinitive alongside a conjugated word. For example, “fui” is qualified by ser and yo, avoiding confusion with ir. English “you” distinguishes singular/plural in answer labels; this version teaches the six table slots including vosotros (Spain), not all regional pronoun variants. Preterite and imperfect are teaching glosses, not a claim of one universal translation in every context. The inherited source requests native-speaker editorial review; arrange that before public release.
